# NKZ-NET-TOOLS-TERMUX-
NKZ NET TOOLS é um painel de ferramentas de rede para Termux e Android, desenvolvido em Python para consultar IP local e público, gateway, DNS, testar conectividade e latência. Projeto educacional da NKZ.




# NKZ NET TOOLS

Painel de ferramentas de rede para Termux e Python.

## Recursos

- Consulta de IP local e IPv6
- Consulta de gateway e DNS
- Teste de conectividade com a internet
- Teste de latencia com ping
- Consulta de IP publico
- Consulta de interfaces de rede

## Instalacao no Termux

    pkg update -y
    pkg install git python iproute2 -y
    git clone https://github.com/NkzAyano/NKZ-NET-TOOLS-TERMUX-.git
    cd NKZ-NET-TOOLS-TERMUX-
    python main.py

Substitua SEU-USUARIO pelo seu nome de usuario do GitHub.

## Aviso

Projeto educacional para diagnostico de rede.
Use as ferramentas de forma responsavel.
